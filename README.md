# Tokens для Windows

Котировки криптовалют прямо на рабочем столе: полоска у края экрана и плавающий
виджет с ценами бирж в реальном времени. Здесь публикуются готовые сборки и журнал
изменений; исходный код приложения закрыт.

## Скачать

Последняя версия — на странице [последнего релиза](https://github.com/unchase/tokens-releases/releases/latest).
Все версии — в [списке релизов](https://github.com/unchase/tokens-releases/releases), что
в каждой изменилось — в [журнале изменений](https://github.com/unchase/tokens-releases/blob/HEAD/CHANGELOG.md).

| Файл | Когда брать |
|---|---|
| `Tokens_X.Y.Z_x64-setup.exe` | обычная установка для себя — без прав администратора |
| `Tokens_X.Y.Z_x64_en-US.msi` | установка для всех пользователей компьютера или через групповые политики |
| `SHA256SUMS.txt` | суммы SHA-256 обоих установщиков — чтобы проверить файл |

## Системные требования

- Windows 10 или Windows 11, 64-разрядная.
- Microsoft Edge WebView2. В Windows 11 он уже есть; установщик доставит его сам,
  если его нет.

## Предупреждение SmartScreen

Установщики пока **не подписаны** сертификатом разработчика, поэтому при первом запуске
Windows может показать окно «Система Windows защитила ваш компьютер». Прежде чем нажать
«Подробнее» → «Выполнить в любом случае», убедитесь, что файл тот самый, — сверьте его
сумму SHA-256 с `SHA256SUMS.txt` того же релиза. В PowerShell:

```powershell
(Get-FileHash .\Tokens_X.Y.Z_x64-setup.exe -Algorithm SHA256).Hash.ToLower()
```

Строка должна совпасть с хэшем этого файла в `SHA256SUMS.txt` (без `.ToLower()`
PowerShell печатает те же буквы заглавными — регистр не важен). Не совпала —
не запускайте файл и скачайте его заново со страницы релиза.

## Удаление

Через «Параметры» → «Приложения»: найдите Tokens в списке и нажмите «Удалить».
Установщик `.exe` при удалении предлагает стереть и данные приложения. Если удаляли без
этого или ставили из `.msi`, настройки остаются в `%APPDATA%\io.github.unchase.tokens`,
а кэш встроенного браузера — в `%LOCALAPPDATA%\io.github.unchase.tokens`: удалите обе
папки, если они больше не нужны.
